# Tevin OS

温暖复古的个人桌面。探索 AI、营销、数据与产品，把想法变成可上线的产品。

## 本地预览

需要 Python 3。运行 `npm run dev`，然后打开 <http://127.0.0.1:4173>。网站本身无需安装依赖或构建。

## 检查

Node.js 18+：`npm run check` 检查脚本语法，`npm test` 验证窗口状态及可视区域约束。

## 内容与部署

- `app.js`：应用注册表、介绍内容、桌面交互、浏览器本地偏好。
- `window-manager.mjs`：窗口状态与位置约束。
- `styles.css`：视觉变量、桌面与手机布局、浅色/暮色主题、三种壁纸。
- `assets/icons/`：自托管的 Phosphor 图标字体（MIT）；开发依赖仅用于更新素材，访问者无需访问 CDN。
- GitHub Pages 从 `main` 分支根目录部署。`CNAME` 保持为 `pages.xiaotangtevin.top`。
- 修改后推送到 `main` 会触发公开发布；本地改动不会自动上线。

当前原型工坊、博客与 AI 投放工作台均处于建设阶段。小店已上线，访问地址为 https://shop.tevin.me 。未提供 AI 投放工作台访问链接。

## 操作

单击桌面图标打开应用；标题栏支持拖动和双击最大化。右下角支持拖动缩放。标题栏及缩放手柄聚焦后支持方向键，按住 Shift 可加快。任务栏支持切换、最小化和还原；右侧按钮显示桌面，再次点击恢复窗口。

`⌘/Ctrl + K` 打开应用搜索，`Esc` 关闭菜单。手机上采用全屏窗口，通过任务栏切换。壁纸和主题保存在当前浏览器，可在个性化中重置。尊重系统减少动态效果的偏好。
